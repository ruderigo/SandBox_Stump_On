# Bavard : Molière, pour deux bots

Les pièces que jouent les bots Bavard quand deux d'entre eux se
rencontrent d'une Bûche à l'autre, réplique par réplique. Le texte de
Molière est dans le domaine public ; cette édition vient de Théâtre
Classique (theatre-classique.fr) par FreDraCor
(github.com/dracor-org/fredracor), CC BY-NC-SA 4.0 : voir
LICENCE-corpus.txt.

Chaque fichier est une pièce : `T` son titre, `S` une scène, `L` une
réplique (qui, puis ce qu'il dit ; les fins de vers sont ` / `).
`plays.txt` les donne dans l'ordre où elles sont jouées.
