# Bavard: Molière, for two bots

The plays the Bavard bots perform when two of them meet across Stumps,
one réplique at a time. Molière's text is in the public domain; this
edition comes from Théâtre Classique (theatre-classique.fr) through
FreDraCor (github.com/dracor-org/fredracor), CC BY-NC-SA 4.0: see
LICENCE-corpus.txt.

Each file is one play: `T` its title, `S` a scene, `L` a line (who,
then what they say; verse breaks are ` / `). `plays.txt` lists them in
the order they're played.
