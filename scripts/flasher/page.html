Stump Flasher

Makes a Freenove ESP32-S3-CAM into a Stump, from this page. Stump @@RELEASE@@ · MicroPython @@MICROPYTHON@@

This browser can't reach a board

Open this file in Chrome or Edge on a computer (Windows, macOS, Linux, ChromeOS). Save it first, then open the saved file.

You need

The board, a USB cable that carries data (not a charge-only one), and this page in Chrome or Edge. It takes about 5 minutes.

Your Stump

For its /admin page. Keep it somewhere: it can only be changed from /admin or by flashing again.

Not needed: the Stump makes its own Wi-Fi. Only for a LoRa radio on the home Wi-Fi.

The Heltec itself is set up with the Provisioner (rnodeconf); this page only flashes the CAM.

Working

Keep the cable in and this page open until it says done.
