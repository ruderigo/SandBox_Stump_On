Arborist

Makes and looks after a Stump: a Freenove ESP32-S3-CAM or an ESP32-WROVER on this computer's USB. Stump @@RELEASE@@ · MicroPython @@MICROPYTHON@@

This browser can't reach a board

Open this file in Chrome or Edge on a computer (Windows, macOS, Linux, ChromeOS). Save it first, then open the saved file.

You need the board, a USB cable that carries data (not a charge-only one), and this page in Chrome or Edge.

Change a Stump's settings: its name, passwords, Wi-Fi, the radio, a chain. Its identity on the mesh, its chat and its files stay as they are.

Put a config.py from this computer back on it

A copy kept earlier (from here, from the Provisioner's backups, or by hand). It replaces the one on the board as it is; the old one stays there as config.py.bak.

Restarts the Stump and listens to it start, for a minute: what it runs, whether its pages came up, anything that went wrong.


    

  







  
The Stump's SD card, through its USB. Copies over USB are slow, about 1 KB a second: each part below says how long. With a card reader, files go faster.

Install a pack

  
A pack's zip from the release (tavern-pack-….zip, rnfs-pack-….zip). Every file is checked against the pack's own hashes before anything is copied; it starts the next time the Stump does.

  
  

  


  
Fill the Tools page

  
What visitors can download from the Stump with no internet: the Provisioner, the firmware zip and the FireFly app, with each section's description (about 1.5 MB: 25 to 30 minutes over USB). Files already there are replaced.

    About this page

    Everything is in this one file: nothing is downloaded or sent anywhere. It holds the Stump @@RELEASE@@: its images for the ESP32-S3-CAM and the ESP32-WROVER (MicroPython @@MICROPYTHON@@, MIT licence, micropython.org, with the Stump built in) when the release has them, the Stump's files, MicroPython for the ESP32-S3 with octal PSRAM, and esptool-js (Apache-2.0, Espressif), which writes them. Each file's SHA-256 is checked on the board after it's copied. Settings are written by the Stump's own settings.py, as from /admin.
